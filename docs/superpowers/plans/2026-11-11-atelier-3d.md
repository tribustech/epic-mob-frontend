# Atelier 3D — plan de implementare

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Configurator public „Atelier 3D” (dressing cu uși glisante) pe epicmob.ro, cu preț live calculat de motorul CRM și lead automat în CRM + email.

**Architecture:** CRM-ul (`C:\Projects\epicmob\epicmob-ofertare`, repo `tribustech/epicmob-ofertare`, branch `main`) primește un modul `lib/atelier/` care traduce o configurație Atelier în `QuoteInput` (corpuri + plăci libere + linii libere), o calculează cu `computeQuote` + `buildSnapshot` existente și expune 3 endpointuri server-to-server sub `/api/atelier/*`, protejate cu cheie. Site-ul (`C:\Projects\epicmob frontend\epic-mob-frontend`, branch `master`) le apelează doar din route handlers proprii, desenează 3D-ul din piesele poziționate întoarse de CRM și trimite emailul prin Postmark.

**Tech Stack:** CRM: Next 15, Prisma 6 (Postgres), vitest, zod, three. Site: Next 16, React 19, Tailwind 4, `node:test`, de adăugat `three` + `@react-three/fiber` + `@react-three/drei`.

**Spec:** `epic-mob-frontend/docs/superpowers/specs/2026-11-11-atelier-3d-design.md`

## Global Constraints

- Prețul afișat = `costs.sellPrice` din `lib/quote/compute.ts#computeQuote` al CRM-ului — niciun alt calcul de preț în site.
- Browserul nu primește niciodată cost, `laborPct`, prețuri de catalog sau cheia API.
- Ușă glisantă: sistem **250 lei/ușă**; oglindă **200 lei/m² + 100 lei lipire/oglindă**; sticlă **400 lei/m² + 100 lei lipire**; toate ca `FreeLine` cu `inCommission: true`; valorile stau în setări CRM, nu în cod.
- Adâncimea introdusă include șina: corp = adâncime − `trackDepthMm` (implicit 100) când există uși glisante.
- Polițele = materialul corpului. Fronturi/uși = material separat (PAL / MDF melaminat / MDF vopsit; MDF vopsit implicit `MAT`, culoare `NORMALA`, modelul „plan drept”).
- Picioare 100 sau 150 mm, plintă mereu (mod `CABINETS`, fără limită de lungime).
- Doar materiale active, `category = 'PLACA'`, cu `pricePerSheet > 0` sau `pricePerSqm > 0`.
- Copy pe site în română; identitate vizuală EpicMob cinematic (tokenurile din `app/globals.css`), nu aspectul Téchne.
- Site: citește `node_modules/next/dist/docs/` înainte de cod (AGENTS.md — Next cu breaking changes).
- Variabile de mediu: CRM `ATELIER_API_KEY`; site `CRM_API_URL`, `ATELIER_API_KEY`, `ATELIER_LEAD_EMAIL` (= adresa proprietarului; nu în cod).

## Review Focus

1. Clientul schimbă lățimea totală după ce a ajustat coloanele → coloanele se rescalează proporțional și suma rămâne exact lățimea totală (test în Task 7).
2. Răspunsuri de preț care sosesc în altă ordine (slider tras repede) → se afișează doar răspunsul ultimei cereri (test în Task 7).
3. Telefon scris diferit (`+40 712 345 678`, `0712345678`, `0712 345 678`) → același client în CRM (test în Task 4).
4. CRM indisponibil sau timeout → prețul arată „momentan indisponibil”, iar trimiterea cererii merge totuși pe email cu configurația atașată (test în Task 6).
5. Material scos din catalog / fără preț între încărcarea paginii și calcul → eroare `MATERIAL_INDISPONIBIL` afișată clientului, nu crash (test în Task 2).

**Reguli (fixate aici, nu în cod existent):**
- Validare: `columns` sumă = `widthMm` (±1 mm) → altfel `COLOANE_SUMA`; fiecare coloană 300–1200 mm → `COLOANA_LATIME`; `heightMm` 1000–3000, `depthMm` 350–800; material corp/front inexistent, inactiv sau fără preț → `MATERIAL_INDISPONIBIL`.
- Înălțime corp `Hc = heightMm − legsMm`. Lungime utilă placă `Lu = sheetLengthMm − 2·cutTrimMm` (materialul corpului). Dacă `Hc ≤ Lu`: un corp `INALT` per coloană. Altfel: corp jos `INALT` cu `Hc − 500` + corp sus `SUSPENDAT` 500 mm (ca „stânga jos / stânga sus” din oferta 240×225); dacă `Hc − 500 > Lu` → `INALTIME_PREA_MARE`.
- Adâncime corp = `depthMm − (doors.type !== 'NONE' ? trackDepthMm : 0)`.
- Corp: `doors: 0`, `frontMaterialId: null` (fără uși batante), `back: { enabled: true, materialId: backMaterialId, mount: 'FALT' }`, `edgeBands.carcassFrontEdgeId = carcassEdgeBandId`, `carcassMaterialId = cfg.carcassMaterialId`, polițe din același material; `plinthEnabled: true`, `legHeightMm = legsMm`.
- Conținut coloană → polițe + bare (bara = `HardwareAdjustments.extra` cu `railItemId`): `POLITE` → `shelves ?? round(Hc/350) − 1`, 0 bare; `BARA` → 1 poliță, 1 bară; `BARA_DUBLA` → 1 poliță, 2 bare; `POLITE_BARA` → 4 polițe, 1 bară; `BARA_SERTARE` → 1 poliță, 1 bară + `drawers ?? 1` sertare interioare.
- Sertar interior (ca în oferta „Comodă + dressing Light Zebrano”), lățime interioară `Wi = widthMm − 36`, `N = pickSlideNominal(adâncime corp)`: plăci libere front+spate `(Wi−62)×70 ×2` (corp, cant 0.4 pe o latură), laterale `N×70 ×2`, front vizibil `(Wi−4)×90` (material fronturi, cant jur-împrejur), fund PFL `(Wi−26)×N`; + 1 glisieră `interiorSlideItemId` în `extra`.
- Uși glisante: `n = count ?? max(2, ceil(widthMm/1000))`; lățime ușă `(widthMm + doorOverlapMm·(n−1)) / n`; înălțime `Hc`. Dacă înălțimea > lungimea utilă a plăcii panoului → `USA_PREA_INALTA` (blocant). Panou: `GLISANTE` → placă liberă în materialul fronturilor (PAL/MDF melaminat); MDF vopsit → linie liberă `frontVopsitCostEur(...)·eurToRon` (`lib/quote/front-pricing.ts`); `OGLINDA`/`STICLA` → placă liberă din materialul corpului + linie `n·(arie·mirrorPerSqm|glassPerSqm + gluePerPanel)`. Plus linie `n·slidingSystemPerDoor`. Toate liniile `inCommission: true`. `track` alternează 0/1.
